# Hashgram Mainnet bootstrap peers for hashgram-node (libp2p).

# One multiaddr per line, each ending in /p2p/<peer-id>. Blank lines and

#   Go    app/params/mainnet.go        (go:embed)
#   Rust  node/hashgram-net/src/mainnet.rs  (include_str!)

# It plays the role of Bitcoin's chainparamsseeds.h: the addresses a brand

# docs/DECENTRALIZATION.md, "Bootstrap peers ship with the binary"). The fix
